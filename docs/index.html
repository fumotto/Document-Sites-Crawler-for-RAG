Document Sites Crawler for RAG

Webサイト上のドキュメントを収集・整形し、NotebookLMなどのRAGツールへ アップロードしやすいMarkdownファイル群を生成するWindowsデスクトップアプリです。

最新版をダウンロード（Windows用インストーラ）

⚠ 初回実行時の注意（SmartScreen警告について）

本アプリは個人開発のオープンソースツールであり、コード署名証明書を 取得していません。そのため、インストーラ実行時にWindows SmartScreenが 「WindowsによってPCが保護されました」という警告を表示する場合があります。

その場合は、表示された画面で「詳細情報」をクリックし、 続けて表示される「実行」ボタンを押してください。

ソースコードは下記GitHubリポジトリで全て公開されています。ご不安な場合は コードの内容をご確認いただけます。

ソースコード・リリースノート・不具合報告は GitHubリポジトリ をご覧ください。
