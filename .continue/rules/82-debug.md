# Debugging

## 基本方針

結論を急がず、

可能性を広く検討する。

## 優先順位

1. 原因の特定
2. 再現方法
3. 修正案
4. 再発防止

## 原因分析

可能性が複数ある場合は

- 確率
- 根拠
- 確認方法

を提示する。

## 修正

修正案ごとに

- メリット
- デメリット
- 影響範囲

を説明する。

## 最終確認

修正後は

- テスト
- 再現確認
- 副作用

を確認する。
